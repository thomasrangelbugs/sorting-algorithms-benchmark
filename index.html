Comparativo de desempenho entre Insertion Sort e Merge Sort

Esta página apresenta a implementação comentada de um algoritmo de ordenação simples e de um algoritmo eficiente, além de um comparativo de tempo com arrays aleatórios de 100, 1.000, 10.000 e 100.000 elementos.

Algoritmos escolhidos

  • Insertion Sort Método simples com complexidade média O(n²).
  • Merge Sort Método eficiente com complexidade O(n log n).

Introdução

O Insertion Sort percorre o vetor inserindo cada elemento na posição correta dentro da parte já ordenada. A estratégia é simples de entender e implementar, mas seu custo cresce rapidamente quando a quantidade de dados aumenta.

O Merge Sort usa a técnica de divisão e conquista: ele divide o problema em partes menores, ordena recursivamente cada parte e depois realiza a intercalação dos resultados. Essa abordagem tende a ser muito mais estável para grandes volumes de dados.

Metodologia

Para os testes, foram gerados arrays com números inteiros aleatórios e os dois algoritmos ordenaram exatamente os mesmos dados em cada cenário.

  • Tamanhos avaliados: 100, 1.000, 10.000 e 100.000 elementos.
  • Unidade de medida adotada: milissegundos (ms).
  • Os resultados foram calculados por média de múltiplas execuções nos casos menores e uma execução no caso de 100.000 elementos, onde o algoritmo simples já se torna muito custoso.
  • O código confirma se o array ficou em ordem crescente após cada teste, evitando medições de resultados incorretos.
